## Computer Organization II
The second course in the computer organization sequence, covering instruction set architecture, processor datapath and control, pipelining, memory hierarchy and caches, and input/output. The course is built around the open-source RISC-V processor and toolchain, with assembly programming and micro-architectural simulation assignments. Enrollment: 200 students.
